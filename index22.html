⚙️ إعدادات Google Sheets

📌 معلومات مهمة: جميع البيانات تُحفظ تلقائياً محلياً أولاً، ثم تُرسل إلى Google Sheets للنسخ الاحتياطية
✓ اذهب إلى Google Cloud Console → Create API Key → Sheets API
✓ ستجده في رابط الجدول بين /d/ و /edit
اسم الورقة للآباء
اسم الورقة للمواليد
🔴 غير متصل - أدخل البيانات أعلاه

📖 خطوات التحضير:

  1. 1. أنشئ جدول في Google Sheets - من sheets.google.com
  2. 2. أضف ورقتين: الأولى اسمها "Parents" والثانية "Chicks"
  3. 3. أضف رؤوس الأعمدة في Parents: Name, Code, Gender, Type, Color, Status, Date
  4. 4. أضف رؤوس الأعمدة في Chicks: Name, Code, Father, Mother, Gender, Type, Color, Ring, Status, Date
  5. 5. اذهب إلى Google Cloud Console - console.cloud.google.com
  6. 6. أنشئ مشروع جديد وفعّل "Google Sheets API"
  7. 7. أنشئ API Key من Credentials → Create API Key
  8. 8. انسخ معرّف الجدول من رابط الجدول (بين /d/ و /edit)
  9. 9. ألصق البيانات في الحقول أعلاه
  10. 10. اضغط "اختبار الاتصال"
